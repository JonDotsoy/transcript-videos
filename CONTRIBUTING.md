# Guía de Contribución

¡Gracias por tu interés en contribuir a este proyecto! A continuación, se detallan las pautas para contribuir de manera efectiva.

## Cómo Contribuir

1. **Reportar Problemas**
   - Si encuentras un error o tienes una sugerencia, abre un [issue](https://github.com/jondotsoy/transcript-videos/issues).
   - Proporciona una descripción clara y detallada del problema o sugerencia.

2. **Solicitudes de Extracción (Pull Requests)**
   - Realiza un fork del repositorio y crea una nueva rama para tu contribución.
     ```bash
     git checkout -b feature/nombre-de-tu-rama
     ```
   - Asegúrate de seguir la [sintaxis de commits convencional](https://www.conventionalcommits.org/).
   - Envía tu solicitud de extracción describiendo claramente los cambios realizados.

3. **Estilo de Código**
   - Sigue las convenciones de estilo del proyecto.
   - Usa herramientas de linting para verificar tu código antes de enviarlo.

4. **Pruebas**
   - Asegúrate de que tu contribución no rompa las pruebas existentes.
   - Si agregas nuevas funcionalidades, incluye pruebas para ellas.

## Código de Conducta

Este proyecto sigue un [Código de Conducta](./CODE_OF_CONDUCT.md) para garantizar un entorno inclusivo y respetuoso. Por favor, léelo antes de contribuir.

## Contacto

Si tienes preguntas, no dudes en contactar al mantenedor del proyecto o abrir un issue.
